# 酒店人事一体化综合管理系统 Web 版运行说明

## 一、运行前提

请先确认已经在 DataGrip 中依次执行过 `sql` 文件夹中的脚本：

1. `01_create_database.sql`
2. `02_create_tables.sql`
3. `03_views.sql`
4. `04_procedures.sql`
5. `05_triggers.sql`
6. `06_indexes_queries.sql`
7. `07_seed_data.sql`

Web 版直接复用数据库 `hotel_hr_system`。

## 二、修改数据库连接

打开 `web_app/db.py`，根据你的 MySQL 配置修改：

```python
"user": "root",
"password": "123456",
```

如果你的 MySQL 密码不是 `123456`，请改成自己的密码。

## 三、安装依赖

在 PyCharm 中打开 `web_app` 文件夹，进入 Terminal，执行：

```bash
pip install -r requirements.txt
```

## 四、启动系统

在 `web_app` 文件夹下执行：

```bash
python app.py
```

看到类似下面内容表示启动成功：

```text
Running on http://127.0.0.1:5000
```

然后用浏览器打开：

```text
http://127.0.0.1:5000
```

## 五、测试账号

所有测试账号默认密码都是：

```text
123456
```

常用账号：

- `front01`：前台账号，可测试客户管理、客房管理、办理入住、退房结算、报表。
- `finance01`：财务账号，可测试薪资生成、发薪、报表。
- `room01`：客房/人事相关账号，可测试员工、考勤、客房。
- `manager01`：经理账号，但测试数据中演示了离职锁定账号，所以默认可能无法登录。

如果想启用 `manager01`，在 DataGrip 中执行：

```sql
UPDATE employees
SET employment_status = '在职', leave_date = NULL
WHERE employee_no = 'E2026006';

UPDATE user_accounts
SET account_status = '启用'
WHERE username = 'manager01';
```

## 六、订单号格式

网页端办理入住时会自动生成推荐订单号，格式为：

```text
ORD + 年月日时分秒
```

示例：

```text
ORD20260713153020
```

只要订单号不重复即可。如果手动修改，建议保持 `ORD` 开头。

## 七、主要功能

- 首页：查看客房数、空闲房、入住中订单、在职员工。
- 客房管理：新增客房、修改房态、删除客房。
- 客户管理：新增、修改、删除客户。
- 员工管理：新增员工、员工离职并自动锁定账号。
- 办理入住：选择客户、空闲房间、前台员工并提交入住。
- 退房结算：选择入住中订单进行结算。
- 考勤登记：登记上班、下班时间和考勤状态。
- 薪资管理：按月份生成薪资，并发放薪资。
- 报表查询：查看当前占用客房、月度营收、考勤汇总、薪资汇总。
- 编号参考：查看表单中需要用到的各种编号。

## 八、常见问题

### 1. 页面打不开

确认 `python app.py` 正在运行，不要关闭运行窗口。

### 2. 无法连接数据库

检查 `web_app/db.py` 中的用户名、密码、端口和数据库名。

### 3. 登录失败

用户名不要带引号，例如输入 `front01`，不要输入 `"front01"`。

### 4. 办理入住失败

常见原因是客房不是 `空闲` 状态，或者订单号重复。

### 5. 日期时间格式错误

日期使用：

```text
2026-07-13
```

日期时间使用：

```text
2026-07-13 12:00:00
```

薪资月份使用：

```text
2026-07
```
