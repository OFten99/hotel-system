# 酒店人事一体化综合管理系统 Web 版运行说明

## 一、运行前提

先在 MySQL 客户端里按顺序执行 `sql` 文件夹下的七个脚本：

1. `01_create_database.sql`
2. `02_create_tables.sql`
3. `03_views.sql`
4. `04_procedures.sql`
5. `05_triggers.sql`
6. `06_indexes_queries.sql`
7. `07_seed_data.sql`

或者直接跑一次根目录的 `python init_database.py`，它按同样顺序执行。
Web 版复用 `hotel_hr_system` 这个库。

## 二、改数据库连接

打开 `web_app/db.py`，按自己机器上的 MySQL 改这两行：

```python
"user": "root",
"password": "123456",
```

密码不是 `123456` 就换成自己的。

## 三、安装依赖

在 `web_app` 目录下开个终端，执行：

```bash
pip install -r requirements.txt
```

## 四、启动

在 `web_app` 目录下：

```bash
python app.py
```

看到类似这样的输出就是起来了：

```text
Running on http://127.0.0.1:5001
```

然后用浏览器打开：

```text
http://127.0.0.1:5001
```

也可以直接双击根目录的 `run_web.bat`。

## 五、测试账号

默认密码都是：

```text
123456
```

- `front01`：前台，能测客户管理、客房管理、办理入住、退房结算、报表
- `finance01`：财务，能测薪资生成、发薪、报表
- `room01`：客房/人事相关，能测员工、考勤、客房
- `manager01`：经理。测试数据里演示了离职锁定账号，所以默认登不进去

想恢复 `manager01`，执行：

```sql
UPDATE employees
SET employment_status = '在职', leave_date = NULL
WHERE employee_no = 'E2026006';

UPDATE user_accounts
SET account_status = '启用'
WHERE username = 'manager01';
```

## 六、订单号格式

网页端办理入住时会自动生成推荐订单号，格式是：

```text
ORD + 年月日时分秒
```

例如：

```text
ORD20260713153020
```

只要不重复就行。手动改的话，建议还是保持 `ORD` 开头。

## 七、主要功能

- 首页：客房数、空闲房、入住中订单、在职员工
- 客房管理：新增客房、改房态、删客房
- 客户管理：新增、修改、删除客户
- 员工管理：新增员工、员工离职并自动锁定账号
- 办理入住：选客户、空闲房间、前台员工后提交
- 退房结算：选入住中的订单结算
- 考勤登记：登记上下班时间和考勤状态
- 薪资管理：按月生成薪资并发放
- 报表查询：当前占用客房、月度营收、考勤汇总、薪资汇总
- 编号参考：表单里要用到的各种编号

## 八、常见问题

### 1. 页面打不开

确认 `python app.py` 还在跑，别把窗口关了。

### 2. 连不上数据库

检查 `web_app/db.py` 里的用户名、密码、端口和库名。

### 3. 登录失败

用户名不要带引号，输 `front01`，不要输 `"front01"`。

### 4. 办理入住失败

一般是客房不是 `空闲` 状态，或者订单号重复。

### 5. 日期时间格式错

日期写：

```text
2026-07-13
```

日期时间写：

```text
2026-07-13 12:00:00
```

薪资月份写：

```text
2026-07
```
